# Governed Objects Specification

The Governed Objects Specification defines portable semantics for organization-owned Governed Objects: durable identity, accepted state, relationships, governance, and history that can outlive the applications, providers and runtimes that operate on them. It also defines optional capability profiles and candidate conformance behavior.

**Status:** `v0alpha1 draft2.2` is an Experimental Draft. It is not final, frozen or certified. It does not establish wire-level interoperability or production stability, and the specification itself declares no implementation conformant.
